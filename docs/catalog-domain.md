# Dominio de Negocio: Catálogo de Vaporizadores

## 1. Categorización de Productos (Taxonomía Vape)

El negocio de vaporizadores se divide en familias de productos muy específicas con especificaciones técnicas particulares:

### A. Desechables (Disposables / Puffs)
- **Definición**: Dispositivos listos para usar que vienen precargados con e-líquido y batería.
- **Atributos Clave**:
  - **Número de Puffs (Caladas)**: Varían comúnmente entre 5,000 y 25,000 puffs.
  - **Batería Recargable**: La mayoría de modelos actuales de más de 5,000 puffs cuentan con puerto USB-C para recargar la batería hasta agotar el e-líquido.
  - **Pantalla Inteligente**: Modelos premium indican el % de batería y el nivel restante de líquido.
  - **Perfil de Sabor**: Ice (frutal mentolado), Bebidas, Postres, etc.
  - **Concentración de Nicotina**: Típicamente 50mg (5%) o 20mg (2%).
  - **Marcas Líderes**: Lost Mary, Elf Bar, Geek Bar, Vozol, Oxbar, Fume.

### B. Pods Recargables (Pod Systems)
- **Definición**: Dispositivos compactos reutilizables donde el usuario recarga el cartucho con líquido de sales o base libre y cambia la resistencia o cartucho cuando se gasta.
- **Atributos Clave**:
  - Capacidad de batería (mAh): 800mAh - 1500mAh.
  - Potencia máxima (Watts): Ej. 15W - 30W.
  - Compatibilidad de cartuchos: 0.6 ohm, 0.8 ohm, 1.2 ohm.
  - Flujo de aire regulable (Airflow control) y tipo de calada (MTL - boca a pulmón, RDL - directo restringido).
  - **Marcas Líderes**: OXVA (Xlim series), Geekvape (Wenax series), Vaporesso (XROS series), Uwell (Caliburn).

### C. E-Líquidos y Sales de Nicotina (E-Liquids & Nic Salts)
- **Sales de Nicotina (Salt Nic)**:
  - Diseñadas para pods de baja potencia (resistencia ≥0.6 ohm).
  - Absorción rápida en sangre y golpe de garganta suave.
  - Concentraciones: 20mg, 35mg, 50mg. Tamaños: 30ml.
- **E-Líquidos Base Libre (Freebase)**:
  - Diseñados para vaporizadores sub-ohm y producción densa de vapor ("nubes").
  - Concentraciones: 0mg, 3mg, 6mg. Tamaños: 60ml, 100ml.
  - Ratio VG/PG: 70/30 común.
  - **Marcas Líderes**: Nasty Juice, Dinner Lady, BLVK Unicorn, Naked 100, Pachamama.

### D. Resistencias, Cartuchos y Accesorios
- Cartuchos de repuesto para cada modelo de Pod.
- Resistencias comerciales (coils): Vaporesso GTX/GTi, Geekvape B-Series, etc.
- Cables USB-C, lanyards, fundas protectoras.

## 2. Factores Críticos de Decisión del Cliente

1. **Autenticidad (Anti-Clon)**:
   - El mercado de vapes sufre por copias chinas no certificadas. La confianza es el pilar de compra número 1. La tienda debe comunicar que cada producto cuenta con sello de seguridad y código QR verificable con el fabricante.
2. **Nivel de Nicotina**:
   - Usuarios en transición del cigarrillo convencional buscan 35mg - 50mg; usuarios recreativos o que reducen consumo buscan 20mg o 0mg.
3. **Velocidad de Entrega**:
   - Las compras de vaporizadores suelen ser por impulso o reposición urgente cuando el dispositivo actual se agota. La promesa de "domicilio hoy mismo en Valledupar" incrementa exponencialmente la conversión.
